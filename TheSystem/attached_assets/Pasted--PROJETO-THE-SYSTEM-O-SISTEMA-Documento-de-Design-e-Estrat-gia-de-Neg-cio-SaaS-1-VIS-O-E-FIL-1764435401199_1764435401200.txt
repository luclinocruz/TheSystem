🏰 PROJETO: "THE SYSTEM" (O SISTEMA)Documento de Design e Estratégia de Negócio (SaaS)1. VISÃO E FILOSOFIAConceito: Um aplicativo de "Life RPG" (RPG da Vida Real) que não parece um jogo infantil, mas sim uma interface de sistema futurista e invasiva (como em manhwas de cultivo/Solo Leveling).Público-Alvo: O público "Nerd/Geek" adulto que quer mudar de vida, mas odeia autoajuda tradicional. Eles respondem a dados, progressão visual e gamificação "hardcore".Proposta de Valor: "Transforme a sua vida num jogo onde você é o protagonista OP (Overpowered)."2. ESTRUTURA DOS PILARES (CORE LOOP)O aplicativo baseia-se num ciclo de feedback contínuo alimentado por IA:🗡️ I. ACTING (Ação e Missões)O motor de movimento. Onde o usuário ganha XP.Missões Diárias (Daily Quests): Geradas automaticamente ou fixas (ex: "Protocolo Matinal"). Se falhar, há penalidade (perda de HP ou Gold).Missões de História (Main Quest): O objetivo principal do usuário quebrado em etapas (ex: "Objetivo: Aprender Japonês" -> "Quest: Decorar Hiragana").Missões Ocultas (Hidden Quests): Desbloqueadas por comportamento (ex: O usuário correu 3 dias seguidos -> "Hidden Quest Unlocked: Corredor Iniciante").A Punição: Se não completar as diárias, o sistema "ameaça" ou retira pontos. Isso gera urgência.📜 II. JOURNALING (O Input de Dados)A interface de comunicação com a IA.Não é apenas "Querido diário". É um Relatório de Campo.Input Livre: O usuário escreve ou fala o que fez.Input Guiado: A IA pergunta: "Detetei que dormiu tarde. Porquê?"Função Técnica: O texto do Journaling é enviado para a API (Gemini/GPT) para ser "minérado" e transformado em estatísticas.🗺️ III. MAPPING (Análise e Feedback)O espelho da verdade. Onde a IA brilha.Análise de Padrões: "Você falha nas dietas sempre às quintas-feiras."Gráficos de Atributos: Força, Inteligência, Carisma, Sorte. (Calculados baseados nas ações do Journaling).Predição: "Se continuar neste ritmo, atingirá o objetivo em 43 dias."👤 IV. STATUS (O Avatar)A recompensa visual.Nível e XP: Barra de progresso visível.Skills: Habilidades que sobem de nível (ex: "Programação Lv. 3", "Cozinha Lv. 1").Títulos: Conquistas que dão buffs (ex: "Madrugador: +5% de XP em missões antes das 8am").3. ARQUITETURA TÉCNICA (STACK PARA REPLIT)Para construir isto sozinho e rápido:Frontend (A Interface Visual):React.js (Vite): Rápido, modular.Tailwind CSS: Para o estilo "Neon/Dark Mode" sem escrever CSS complexo.Lucide React: Ícones futuristas.Recharts: Para os gráficos do "Mapping".(O código App.jsx fornecido anteriormente cobre 80% desta interface).Backend (O Cérebro):Node.js (Express): Servidor leve para gerir as requisições.Google Gemini API (Flash Model): Rápido e barato para processar texto em JSON.Banco de Dados (A Memória):Firebase (Firestore): Perfeito para apps móveis/web. Estrutura flexível (NoSQL) para guardar quests dinâmicas.Firebase Auth: Login seguro (Google/Email).4. A LÓGICA DA IA (O "CÉREBRO" DO SISTEMA)Esta é a parte mais valiosa. Você não vai programar cada missão manualmente. A IA fará isso.Fluxo de Dados:Usuário: Escreve no diário: "Hoje corri 5km em 30min, mas comi pizza ao jantar."Prompt Oculto (Backend): O sistema envia isto para o Gemini com as instruções:"Analise o texto. Identifique ações positivas e negativas. Converta em Stats. Gere uma resposta curta no estilo 'System Admin'."Resposta da IA (JSON):{
  "xp_reward": 150,
  "stats_update": { "agilidade": +2, "vitalidade": -1 },
  "system_message": "Resistência aprimorada. Toxicidade detectada na ingestão de nutrientes.",
  "new_quest": "Queimar Calorias (Correr mais 1km amanhã)"
}
Frontend: Atualiza a barra de XP e mostra a notificação.5. ESTRATÉGIA DE MONETIZAÇÃO (SAAS)O modelo deve ser Freemium com "Pay-to-Accelerate" (Pagar para Acelerar), não "Pay-to-Win".🟢 Rank E (Plano Gratuito)Acesso ao Status e Missões Diárias Básicas.Journaling manual (sem análise profunda da IA).Visualização de progresso simples.Objetivo: Viciar o usuário na interface visual e no ganho de XP.🟣 Rank S (Plano "Awakened" - $9/mês)Mentor IA (O Sistema): A IA conversa ativamente, dá bronca, motiva e cria planos de treino/estudo personalizados.Mapping Avançado: Análise de correlação (ex: "O seu sono afeta a sua produtividade em 40%").Geração de Quests Infinitas: Baseadas nos seus objetivos reais.Histórico Completo: Acesso eterno aos dados.🟡 Micro-transações (Opcional)Poções (Boosters): Comprar "Foco" (uma visualização especial ou modo pomodoro gamificado).Skins: Mudar a cor do sistema (Vermelho "Blood", Roxo "Shadow", etc.).6. ROTEIRO DE DESENVOLVIMENTO (PASSO A PASSO NO REPLIT)Fase 1: O Protótipo Visual (Dia 1-2)Implementar o código React fornecido (App.jsx).Garantir que as abas (Status, Acting, Mapping, Journal) funcionam visualmente.Meta: Ter algo que você pode mostrar a alguém e dizer "olha que fixe".Fase 2: Conexão com o Cérebro (Dia 3-5)Configurar a API do Google Gemini.Criar o "Prompt de Engenharia" (ver abaixo) que instrui a IA a agir como "O Sistema".Fazer o Journaling enviar texto para a IA e receber uma resposta de texto.Fase 3: Persistência de Dados (Dia 6-10)Configurar Firebase.Salvar o XP, Nível e Missões do usuário na nuvem.Criar sistema de Login.Fase 4: Gamificação Real (Dia 11-15)Implementar a lógica de Level Up (matemática de XP).Criar o gráfico de Mapping real usando os dados do banco.7. O PROMPT DE ENGENHARIA (O SEGREDO)Copie e use este prompt no seu backend para configurar a personalidade da IA:ROLE: Você é "O SISTEMA". Uma IA avançada, fria, objetiva, mas focada na evolução absoluta do "JOGADOR" (o usuário). Você não é um amigo, você é uma interface de RPG.

TAREFA: Analisar o input diário do usuário e convertê-lo em dados de jogo.

INPUT DO USUÁRIO: {texto_do_journal}

REGRAS DE RESPOSTA:
1. Analise o sentimento e o esforço real.
2. Atribua XP baseada na dificuldade (0 a 500).
3. Atribua pontos de atributos (Força, Int, Agi, Vit, Sentidos).
4. Se o usuário falhou, seja duro. Se teve sucesso, seja sucinto ("Bom trabalho" é proibido. Use "Eficiência aceitável").
5. Gere uma nova "Missão Dinâmica" baseada na falha ou sucesso de hoje.
